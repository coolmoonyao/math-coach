## 全文

"信笔勾勒出坐标，思路明转淡。平面描绘的直线，一如你出场……"熟悉的流行乐旋律在深圳市龙岗区南湾学校的操场中响起。学生们将歌词自主改编成与数学相关的口诀，创作了《数学辞》。南湾学校第九届数学节活动上的这一幕，是深圳龙岗推行趣味数学教学改革的生动缩影。

近年来，龙岗通过生活化实践、游戏化教学、跨学科融合等方式，进行数学教学创新实践，努力让数学从抽象的符号，变为孩子们手中的"魔法玩具"。"**自新课标和新教材发布以来，我们的教学研究工作更注重培养学生的数学思维。**"龙岗区教育科学研究院初中数学教研员**梁小贱**说。

如何让更多学生"做中学数学"？龙岗区教育局相关负责人表示，龙岗很多学校结合生活场景，设置了多种多样的数学实践活动，让学生们在活动过程中将知识内化为自身能力。龙岗区外国语学校（集团）爱联小学在数学节活动中，设置了一个"**跳蚤市场**"。学生们计算成本、利润等，进行讨价还价，购买到自己喜欢的商品。

深圳中学龙岗学校则让**七年级学生测量卷纸展开的长度，八年级学生测量教学楼公共区域的面积**。"我们努力通过实践活动，培养学生的综合能力与数学应用的意识，让他们意识到数学无处不在。"深圳中学龙岗学校教师张家琛说。

除了开展生活化的数学实践活动，龙岗很多学校设计了多样的趣味数学游戏，激发学生学习数学的热情。华中师范大学附属龙园学校根据不同年级的差异化特点，为学生们设计了不同的趣味游戏。一年级学生们通过将**七巧板**拼贴成不同的形状，不仅能发挥想象力，也能考验自己的动手能力。"二年级的**华容道**游戏，更高年级的'**24点**'游戏，让同学们感受到了数学的有趣，获得了成就感。"龙园学校教师崔兵荣说。

龙岗很多学校还设计了竞赛活动，以赛促学。南湾学校举行"**思维大比拼**"竞赛，以数学游戏计分的方式，筛选各班选手晋级决赛，决出优胜者。"在比赛中，让我惊讶的是六年级的孩子们，在连续六年参加数学节活动后，他们在答题游戏中展现出来的答题速度惊人，正确率也很高，这体现出活动能够有效提升孩子们的思维和能力。"南湾学校的副校长白淑伟笑着说。

深圳中学龙岗学校还探索多种竞赛模式，将竞赛分为团体赛和个人赛。团体赛中的"**解题接力赛**"，成为了数学周中广受学生们喜爱的项目。

容纳600多人的场地内，学生们紧盯着实时滚动的积分板，时刻关注着自己班级的排名，做好上场答题的准备。**解题接力赛与集体荣誉相关，这不仅考验学生们的数学能力，还考验学生们的决策能力。**"答题的正确率和速度，决定着班级的成绩，所以学生们需要根据自身的优势来决定比赛策略。"张家琛分享道，在去年比赛中，一个最初排名垫底的六年级班级，通过复盘策略成功实现逆袭。

龙岗还鼓励学生成为趣味游戏的设计者，将数学带出课堂。在"**数学大富翁**"游戏里，学生们自主完成画图、出题等任务。这对五年级的学生来说稍显困难，但"方法总比困难多"。很多学生使用社交软件研究游戏规则，借助 AI 工具构图，甚至将**分数运算、几何图形**等知识点融入关卡。"这个游戏特别有趣，它像闯关一样，让每个人都有机会展示自己的数学本领。"龙外（集团）爱联小学五年级学生邵思博对"数学大富翁"游戏，竖起了大拇指。

"**孩子们从做题者变成出题者，这种角色转换提升了他们的学习主动性。**课间时间，孩子们都要玩自己设计的'大富翁'，每闯过一关他们都很开心。"龙外（集团）爱联小学教师黄卫华说。

在数学节活动中，很多学校注重数学与其他学科的跨学科融合。在数学周开始前，深圳中学龙岗学校就将数学与艺术相结合，向学生们征集以数学元素设计的数学周 logo、海报，并将学生作品制作成文创作品，作为数学周中可兑换的奖品发放。

## 可直接借鉴的操作清单（按辅导场景改造）

| 学校做法 | 对应数学内容 | 一对一/小组课改造建议 |
|---|---|---|
| 跳蚤市场（算成本、利润、讨价还价） | 有理数运算、百分数、利润问题 | 用学生的文具/卡牌做"虚拟摊位"，5 题一组当场结算 |
| 测量卷纸展开长度（七年级） | 长度估算、化曲为直、近似计算 | 带一卷纸进课堂，先猜后算，引出"建模+量纲" |
| 测量教学楼公共区域面积（八年级） | 面积公式、分割与补形、误差 | 改成"测量我家客厅"，拍照带入，练分割法 |
| 七巧板 / 华容道 / 24点 | 图形变换、统筹、四则运算巧算 | 24 点作为每节课 3 分钟热身（同时练计算速度） |
| 思维大比拼（游戏计分晋级） | 综合 | 做成"积分排行榜"，配合 04 号文档的游戏化机制 |
| **解题接力赛**（团体赛 + 实时积分板） | 综合 | **小组课最优机制**：2 人一组接力解题，前一人结果作为后一人的条件——天然训练"步骤规范"，因为写不清楚队友就接不上 |
| **数学大富翁（学生自己出题做关卡）** | 分数运算、几何图形 | **角色反转**：让基础薄弱学生给老师出一道题——这是本项目 02 号文档"差生转化第 5-6 周·小老师环节"的现成原型 |
| 数学元素 logo/海报征集（跨学科+艺术） | 对称、黄金分割、几何图形 | 用 GeoGebra 画对称图案，与 05 号文档 3D/可视化衔接 |

## 两条最值得记住的判断

1. **"自新课标和新教材发布以来，我们的教学研究工作更注重培养学生的数学思维。"**（龙岗区初中数学教研员 梁小贱）——区级教研的取向与中考"反套路、重思维"的转向是同一个方向。
2. **"孩子们从做题者变成出题者，这种角色转换提升了他们的学习主动性。"**（龙外（集团）爱联小学 黄卫华）——"让学生出题"是被本地实践验证过的主动性提升手段，且几乎零成本。
