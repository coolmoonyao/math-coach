## 摘要（官方收录全文）

七年级是小学与初中衔接的关键时期，教育环境的改变及其他新特征的出现，一定程度上影响学生学习适应性能力，影响各门学科的成绩，**尤其是对数学学科成绩的影响比其他学科更为显著**。

研究参照周步成教授编制的《学习适应性测验》，改编得到《七年级学生数学学习适应性调查问卷》，对新疆昌吉市某中学七年级学生问卷调查（SPSS 26.0 分析）并访谈。

**问卷结果**：
1. 七年级学生整体数学学习适应性处于**中等水平**，在学习兴趣与动力维度表现最好，**在教师和父母影响维度上表现最差**；
2. 数学学习适应性在民族和班级上存在显著差异，在性别、是否独生子女和父母学历方面不存在显著差异。

**影响因素（结合访谈）**：
1. 中小学数学教材内容和课程目标的变化；
2. 教师教学方式的变化，师生关系紧张；
3. 学生学习习惯欠缺和学习心态不稳定；
4. 父母的关心和班级学习氛围的影响。

**建议**：
1. 在有理数、式、应用题、空间与图形四方面把握中小学教材内容衔接；
2. 教师应把握适宜的教学进度、建立和谐师生关系、指导学生数学学习方法、改善自身教学方法；
3. 学生养成良好数学学习习惯，学着做学习数学的主人；
4. 家长合理期待，鼓励劝导，做好榜样。
