# 2021深圳中考数学试题解析：新中考首年，解答题题型有创新、变化大

卓越教育深圳中考数学团队认为，如果用一个字来形容2021年深圳中考数学卷，那就是"新"。

今年深圳中考数学试卷整体稳中有变。分值和考试时长与去年一致，试卷结构从2020年11月全市新中考适应性考试开始发生了变化。

**题目总数量由23题删减至22题。其中，选择题由12题变为10题，填空题由4题变为5题。选择填空总分值由48分变为45分，解答题题量不变仍为7题，总分值由52分变为55分。**

## 解答题题型：有创新、变化大

今年数学卷中的选择和填空题，难度与之前相比变化不大，但解答题的题型设置有创新，出现了新题型，变化较大：

1. **阅读量变大**：这是今年数学卷的一个新特点，突出对学生的阅读分析能力、推理探究能力的考查。有学生戏称"读题半小时，做题五分钟"。
2. **压轴题没考二次函数**：学生练习较多的二次函数综合题今年没有考，而代以几何探究题。往年解答题第一题实数运算今年没有考，分式化简求值题位置前移变成了第一题，第二题为新出现的轴对称作图及面积计算。
3. **首次出现的新题型**：第21题为首次出现的新题型，代数几何综合题，考查数形结合，用代数方法解决几何问题，综合了反比例函数、矩形、一元二次方程等知识点，题目新颖。
4. **几何综合探究题**：几何综合探究题连续两年出现，并且今年取代二次函数放在最后一题。不过其中涉及到的几何模型属于常见类型。

## 给初一初二同学的备考建议

七八年级的同学一定要夯实基础，加强数学能力的培养。要理解题意，还要学会联系前后，将知识融会贯通。平时要加强数学阅读训练，培养阅读思考，发现、提出问题，分析解决问题的能力。
