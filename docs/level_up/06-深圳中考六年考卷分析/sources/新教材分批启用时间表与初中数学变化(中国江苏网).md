# 新学期中小学全面启用新教材，有何不同？（2022版课标新教材分批启用时间表）

2022年，教育部发布《义务教育课程方案和课程标准（2022年版）》，为新教材编写提供了依据。改革分步推进：

- **2024年秋季**：新教材在小学一年级和初中**七年级**率先启用；
- **2025年秋季**：扩展至小学二、三年级和初中**八年级**；
- **2026年秋季**：覆盖小学、初中所有年级（**初中九年级语文、数学、英语、历史、道德与法治等同步更换新教材**）。

这标志着历时四年的教材改革进入全面落地阶段。

## 初中数学新教材的变化（北师大版新教材编写组核心作者、南京市致远初级中学高级教师何君青）

"从内容设计看，新教材更关注学生未来发展，以九年级教材中'**一元二次方程韦达定理**'为例，旧教材侧重呈现证明过程，新教材则突出**探索发现的过程**，让数学结论的获得'有道理'，并强调知识与经验之间的联结。在章节编排上，九年级'**圆**'的内容将原本分散的'**点与圆**''**线与圆**'整合为一个整体，符合数学对象研究的规律，一般都是先研究对象本身，再研究相互关系。此外，**新教材增加了大量原创素材，强化综合实践**，提升学生运用数学解决生活实际问题的能力。"

何君青认为，初中数学新教材**结构化特征显著**，体现出数学的本质特征，并在问题设计上持续引发学生思考，旨在实现"转识为智"的理念。

## 其他学科的共性变化（供跨学科参照）

- 新教材改版的核心变化，是从侧重知识学习转向培养核心素养和真实问题解决的能力，从"学会"转向"会学"。
- 小学新教材更强调**跨学科学习，要求不少于10%的跨学科主题学习活动**。
- 一线教师指出：预习的目标不再是提前记住知识点，而是带着结构化的问题接触文本；家长和学生应打破"刷题即学好"的认知误区。

> 对本项目的含义：2026年6月参加中考的学生（2023年秋入七年级）在初中阶段使用的是**旧版北师大教材**；**2027年6月中考将是"依2022版课标修订的新教材"第一届**（2024年秋入七年级）。2026年秋季起，九年级也同步启用新教材。
