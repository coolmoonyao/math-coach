## 一、整体评价

2023年深圳中考数学卷结构和去年相同，题型分值占比也一致，**10道选择题加5道填空题，共45分，解答题7道分值共55分**。

考完之后学生普遍反馈：选择题前9题都很简单，第10题相比往年难度也要低一点，填空题前4题也偏基础，填空题最后一题稍有难度，除了解答题最后一题的最后一问，试卷其他题目的计算量不大。整套试卷**考查基础方面偏重**，学生大部分题目做起来比较顺，**试卷中几何题型的考查占比依然较大**。虽然学生反馈试卷简单，但是这份试卷要考满分也是很难的，尤其是最后一道压轴题的最后一问对于A+的学生来说难度都是非常大的。

## 二、试卷特点

- 选择题最后一题考查动点问题和函数图象结合，很多学生反馈基本不会做错；从适应性考试开始，**选择题压轴的难度降低的信号已经非常明显**。
- 填空题最后一题考查三角形折叠变换与相似的综合，与适应性考试第15题异曲同工，绝大多数学生没有准确作答，**说明学生对于相似的综合运用知识掌握比较欠缺**。
- **对于深圳中考来说，几何综合是命题人热衷考察的题型**，希望24年考生重视几何板块复习，尤其是三角形的全等及相似、平行四边形及特殊的平行四边形，同时加强计算能力。
- **二次函数压轴题型今年仍然没有考到**（与适应性考试题型一致），但猜测二次函数在省考趋势下一定会在接下来中考中"粉墨登场"。
- 第20题圆的解答题：第一问证明切线，第二问计算线段长度。**圆的选拔作用已经很多年不在中考中作为主要的版块了**，不必做关于圆的偏题和怪题。
- 第21题是二次函数的探究应用类题型，与今年深圳适应性考试第21题考法类似，很多学生直到考试结束都不清楚具体在考察什么，**学生还是缺少数学生活实际的应用**。
- 第22题是四边形综合探究题，由矩形到菱形再到一般平行四边形的变化中感知一线三垂直相似模型的应用，考查类比推理、分类思想。
- 切忌为了留出时间做压轴题而快速完成选填题。

## 三、与省考/新课标的关系

自**2020年深圳取消中考考试说明**以来，深圳的中考适应性考试以及平常的模拟考试**依照新课标进行命题**，进一步增强教学与考试的衔接。相比今年广东省考数学卷，深圳今年中考数学卷难度会更大一些，考查重点及考法也有很大不同；相比省考特别注重考查基础知识，深圳中考数学除考查基础知识掌握情况外，**更加注重考查数学创新性、类比探究和实践应用能力**。此外学生也要重视深圳市统一的适应性考试相关的题型和考法。

## 四、给2024年考生的备考建议（五条，与2024、2025年版高度一致）

1. 重视课本：考试题型都是来源于课本的基本概念、公式和定理，有些考题就是来自教材的原题进行改编，先吃透课本上的黑体字和例题。
2. 注重知识模型的归纳总结。
3. 错题整理，定期反思和训练。
4. 注意审题，圈画关键条件和关键词。
5. 提前规划限时训练的时间。
