# "做题换资源养宠物"类教学产品：适配性分析与自建方案

> 编写日期：2026-09-01
> 回答两个问题：① 这类产品对我的学生合适吗？② 如果合适，有哪些主流开源方案可以在我自己的服务器上简易部署？
> 信源：产品官方页面、GitHub 仓库元数据（2026-09-01 实时查询）、同行评审元分析（Psychological Bulletin）、《大西洋月刊》调查报道。原文存档见 `sources/`。

---

## 零、结论先行

**有条件合适——对"基础薄弱、动机不足"的学生合适，对"中考冲刺生"不合适；可以自建，但不要指望开源项目开箱即用。**

三条具体判断：

1. **人群上**：适合初一衔接期与基础薄弱生（他们缺的正是外部结构与即时反馈，见 02 号文档"初一上学期自我调节断档期"的政治大学追踪研究）；**不适合年级前三的冲刺生**——深圳中考已转向"反套路、重思维"，他们需要的是 uninterrupted 的深度思考时间，宠物养成的外部刺激只会挤占它。
2. **机制上**：**奖励必须绑定到"数学行为的质量"，绝不能绑定到"做题数量"或"登录打卡"**。这不是道德要求，是数据结论：把奖励绑定在"参与/完成"上，对内在动机的损害效应是 d = −0.40 / −0.36；而**正向反馈**能提升内在动机 d = +0.33（Deci, Koestner & Ryan, 1999，128 项实验的元分析）。
3. **工程上**：**先跑 MVP，再上服务器。** 三个中文"班级宠物"开源项目均为 2026 年新建、Star 数 0—1、两个没有开源许可证、基本无社区——你部署了就是唯一的维护者。建议第一阶段用"纸质积分 + 电子表格"验证机制有效性，第二阶段再上 ClassPet（唯一有 AGPL-3.0 许可、有数据隔离与假期冻结设计）。

## 一、这类产品是什么：三条产品线

### 1.1 国际原型：Prodigy Math（"答对题才能施法/收宠"）

- **规模**：官方称被**超过 5000 万学生**使用、**10 万余名教师**推荐，覆盖 1—8 年级数学（另有 Prodigy English 1—6 年级），含 1500+ 项课标对齐的数学技能（来源：Prodigy 官网 https://prodigygame.com/main-en/blog/educational-games-vs-blooket）。
- **机制**：100+ 只可战斗/解救/收集的宠物；**孩子必须答对数学题才能施法或让宠物出战**，难度由自适应算法按学生水平调整；答对后角色与宠物获得经验升级。
- **官方效果数据（须注意：均为 Prodigy 委托的家长/教师调查，属厂商自证）**：91% 家长称孩子喜欢用；某学区学生平均每月多掌握 68% 的数学技能；96% 家长与教师对其教育影响满意；学生数学乐趣提升 2 倍。
- **商业模式**：免费 + 会员（约 $9.95/月）解锁更多宠物、装备与奖励。
- **第三方批评**：付费墙在班级里制造"有/没有"的可见分化；数学内容在 7—8 年级偏薄偏幼（来源：infinilearn《Math Games for the Classroom That Actually Teach (2026)》）。

### 1.2 国际变体：Blooket（"答题换开箱"）

- 由 Ben Stewart 2018 年读高中时创办，现有约 20 名员工、**数百万活跃用户、23 种游戏模式**（创始人受访数据）。
- 机制：教师导入题集，学生在 Gold Quest、Tower Defense 等主题模式中答题换取游戏内优势；可自定步速，可作为作业布置。
- **争议点**：设有**类似抽卡的机制**——玩家用游戏内货币购买卡包，小概率开出稀有"Blooks"形象，并催生了大量晒"出货"的 YouTuber 二创生态。创始人本人的辩护是：Blooket 是用来替代抽认卡和练习纸、复习已吸收的事实性知识的，**"如果你在课堂上用 Blooket 用了一小时，那就出问题了"**（来源：《大西洋月刊》报道，见 sources/）。

## 二、证据：支持做这件事的四条理由

1. **游戏化对数学学习动机有中到小的显著正效应**：Ratinho 等（2026）元分析 g = 0.383 [0.11, 0.66]，p = 0.0218；Conmy 等的元分析 g = 0.30（详见本主题主文档及 sources/）。
2. **即时反馈是被验证的最强单一要素**：与本主题"10 题一组、当场对答案、错题当场讲"的既有做法一致，宠物系统只是把反馈可视化、可累积。
3. **初一衔接期恰恰需要"外置的自我调节"**：政治大学对 2102 名七至八年级学生的三波追踪发现，自我调节对低成就者的保护效应在七年级上学期一度消失（过渡期干扰）。宠物系统提供的是**外部结构**（可视化进度、连续性、可预期反馈），正好补上这个断档（详见 02 号文档第四章）。
4. **深圳学生的注意力争夺战**：罗湖某中学 33% 学生存在网络成瘾倾向、深圳初中生网络成瘾率 14.4%—15.5%（见 02 号文档）。在一个注意力被短视频训练过的学生身上，"完成—得资源—看成长"的短闭环比"你要为中考努力"的长叙事更有效。

## 三、证据：反面的五条警告（必须认真对待）

1. **外在奖励会挤出内在动机，且对儿童损害更大。** Deci、Koestner & Ryan（1999）《Psychological Bulletin》128 项实验元分析：
   - 参与即给奖 d = **−0.40**、完成即给奖 d = **−0.36**、按表现给奖 d = **−0.28**（对自由选择的内在动机）
   - 对自陈兴趣：d = −0.15 / −0.17
   - **正向反馈（positive feedback）反而提升**：自由选择行为 d = **+0.33**、自陈兴趣 d = **+0.31**
   - **实物奖励对儿童的损害大于对大学生**
   → 直接含义：**"做题就给宠物币"是最糟的设计（engagement-contingent，d = −0.40）；"你这一步的辅助线添得很聪明"是最好的设计（positive feedback，d = +0.33）。**

2. **时间可能被宠物吃掉，而不是被数学吃掉。**《大西洋月刊》记者的实地观察：11 岁的儿子玩 Prodigy 约 10 分钟，**真正用于回答数学题的时间不到 30 秒**；答错时游戏不暂停诊断错因、不引导正确答案，只继续推进战斗；唯一让他慢下来的是被迫观看付费会员广告。

3. **抽卡/开箱机制不要碰。** Blooket 的 loot-box 式设计已经催生"晒出货"的 YouTuber 生态——它训练的不再是数学，而是赌博式的可变奖励期待。深圳本地 33% 网络成瘾倾向的背景下，再给学生加一个可变异的奖励钩子，风险不对称。

4. **"机械操作"陷阱。** 本主题主文档已记录 UIS 的 GeoGebra 干预研究警示：约五分之一学生只是机械拖动滑块而不思考。同理，学生会"为了喂宠物而快速乱选答案"——**当奖励绑定数量，学生会优化速度而不是正确性。**

5. **冲刺生不需要它，甚至会被它伤害。** 深圳中考 2026 年已严格回归 7:2:1 且"前易后难、梯度陡峭"，压轴题要求 uninterrupted 的现场推导（见 06 号报告）。给一个内生动力充足的尖子生加宠物系统，等于用外在动机替换他已有的内在动机。

## 四、适配判断表

| 学生类型 | 是否建议用 | 建议形态 | 关键约束 |
|---|---|---|---|
| **初一新生（基础薄弱）** | ✅ 建议 | 教师手动打分的宠物/养成系统 + 断点清单可视化 | 奖励绑定"断点补完"与"规范步骤"，不绑定题量；配合 02 号文档 4.3 的"今天三句话" |
| **初中差生（含习得性无助）** | ✅ 建议，且是最大受益者 | 低门槛、高频次、可宣讲的成功可视化（宠物等级就是"我进步了"的物证） | **不要设饥饿衰减/缺席惩罚**（会二次挫败）；首周必须保证"第一次交作业就全对"（见 02 号文档 5.3 八周方案） |
| **初二中等生** | ⚠️ 可用但轻量化 | 只做"周结算"：一周一次宠物升级，不做每节课 | 观察是否出现"为积分而学"的迹象（只在能给分的任务上努力） |
| **年级前三冲刺生** | ❌ 不建议 | 用"过程规范审计 + 压轴分层训练"替代 | 他们的边际收益在深度思考时间，任何娱乐化界面都是净损耗 |
| **小组课（3—6 人）** | ✅ 最适合的场景 | 光荣榜 + 团队任务 + 宠物 | 同伴认同需求在初中超过父母认同（见 02 号文档 4.2），小组排行榜的效力高于一对一 |

## 五、设计红线（七条，违反任何一条都应停掉）

1. **奖励绑定"质量行为"，不绑定"数量/参与"**：补完一个断点、订正正确、写出完整判定依据、主动给同伴讲清一步——这些才给资源。（依据：Deci 1999，engagement-contingent d = −0.40）
2. **正向反馈为主，实物/虚拟货币为辅**：具体、指名、到步骤的表扬（"你刚才添的这条辅助线，把分散的条件集中到一个三角形里了"）比任何金币都有效（d = +0.33 vs −0.40）。
3. **禁止抽卡/开箱/随机奖励**：可变比率奖励是成瘾机制，不是教学机制。
4. **宠物环节每节课 ≤ 5 分钟**：参考 Blooket 创始人自己的判断——用满一小时就是出问题了。
5. **对差生关闭"饥饿衰减/缺席倒扣"**：ClassPet 等系统自带饥饿衰减与复活机制，对差生是二次惩罚，建议关闭或改为"只涨不跌"。
6. **数据留在自己的服务器，无广告、无第三方追踪**：你是小区里的辅导老师，家长信任建立在"不拿孩子数据做别的"上。
7. **每次课给家长的反馈必须是"数学证据"，不是"宠物等级"**：宠物是钩子，不是成果；家长周报里要有"本周补完 2 个断点、计算失误从 7 次降到 2 次"这样的具体数据。

## 六、自建方案：三层架构与候选清单

### 6.1 推荐架构

```
[ 内容/判题层 ]        [ 激励/宠物层 ]        [ 记录/沟通层 ]
ClassQuiz（答题）  →   班级宠物园/ClassPet →  家长周报（Excel/图表）
Anki（错题间隔重复）    （积分→宠物成长）
H5P / Moodle Quiz
```

**关键提醒**：目前所有开源"班级宠物"项目都**只做积分与养成，不含题库、不含自动判题**。所以你必须自己拼装两层——这也是为什么不建议一上来就上服务器。

### 6.3 三条部署路线（按投入从低到高）

**路线 A｜零代码 MVP（建议先跑 4—6 周）**
- 工具：一个 Excel/飞书表格（学生 × 行为积分）+ 一套宠物图片（可用 makid 之类产品的风格自己做，或用 Emoji 进化链 🥚→🐣→🐥→🐔）
- 规则：只有四类行为给分——**断点补完（+3）、订正正确（+2）、步骤规范完整（+2）、给同伴/老师讲清一步（+3）**；做错题量不给分。
- 目的：先验证"我的学生吃这一套吗"，再决定要不要上服务器。

**路线 B｜单机宠物系统（推荐，半天可上线）**
- 装 **ClassPet**（唯一有 AGPL-3.0 许可、数据隔离与假期冻结设计）或**班级宠物园**（83 条评价规则开箱可用、SQLite 零配置、有在线演示可先看）。
- 部署要点（ClassPet，官方 README）：服务器需 Node.js v20+ 与 PM2 → 配置 `DATABASE_URL`（SQLite 即 `file:./dev.db`）、`NEXTAUTH_SECRET`、`NEXTAUTH_URL`、`AUTH_TRUST_HOST=true` → `npm install` → `npx prisma db push` → `npm run build` → `pm2 start npm --name "classpet" -- start` → `pm2 save && pm2 startup`。
- **务必先关闭饥饿衰减**（差生保护），并把"班级商店"的兑换物设为**数学相关的实物/特权**（免作业券、选座权、挑一节课的例题），而不是更炫的虚拟道具。

**路线 C｜完整两层（适合小组课，1—2 天）**
- ClassQuiz（答题竞赛与即时判题）+ 宠物层（积分结果）双容器部署，用 Docker Compose 各跑一个服务，反向代理到一个域名（建议内网或仅家长可访问）。
- 数据流向：ClassQuiz 导出每场答题结果 → 人工/脚本映射为积分 → 录入宠物层。
- 这一层没有现成集成，需要你自己写几十行脚本，或者干脆**手工录入**（小组课人数少，手工反而更快也更可控）。

### 6.4 明确不推荐的方案

- **Habitica 自建**：运维成本与你的学生规模完全不匹配（一个辅导老师 + 几个学生）。
- **任何带抽卡/开箱/随机奖励的产品**（含商业产品中的对应模块）：见红线第 3 条。
