# "互联护苗2024"主题网络活动启动

本报记者 骆倩雯：昨天，"互联护苗2024"主题网络活动正式启动。活动将自5月持续至12月，聚焦"生态治理""辟谣科普""普法教育""网络文明"四个主题，通过开展网络举报专项行动、组织系列科普行动、打造系列普法课程、推出系列文化产品，共同唱响护航未成年人健康成长、共创文明网络生态的主旋律。

启动仪式上发布了《青少年互联网使用情况调查报告（2024）》。根据调研，80.1%的青少年每周甚至每天都会上网，触网频率非常高，上网的活动也很丰富多彩。网上学习是上网的首要目的，占比为47.8%；其次，玩游戏、看短视频也是重要活动。综合来看，青少年上网兼顾学习与娱乐。

最近一年来，人工智能话题热议不断，国内外涌现出很多AI领域的突破性创新技术和产品。根据调研，45%左右的青少年尝试使用过AI产品，就具体的使用目的而言，目前主要还是功能尝鲜以及帮助生成基础内容，仍处于探索阶段。但更多青少年只是停留在听说、并未使用的阶段，AI知识的相关普及和教育工作仍然非常有必要。

报告指出，近年来，随着各项网络生态治理活动的开展以及网民网络素养的提升，网络各领域治理成效日益显著，但仍然面临许多治理难点和问题。在不随意添加陌生人、抵制网暴、识别网络诈骗上，青少年有相对强的共识；但在分辨网络谣言、警惕恶意软件和不良内容举报上，青少年具备的技能和意识还相对薄弱，需要进一步提升。

报告中提出了三点关于青少年网络权益保护的建议：要以家校联合为依托，共同推进网络普法和教育工作；鼓励青少年在人工智能等前沿科技领域，多探索和实践，提升自身"高阶"的上网素养；同时，呼吁各平台继续加强内容管理，营造良好的社会舆论氛围和正向价值观。

据介绍，自2018年以来，市委网信办已连续6年举办"互联护苗"品牌活动，深化各单位、各部门未成年人保护工作协同。
