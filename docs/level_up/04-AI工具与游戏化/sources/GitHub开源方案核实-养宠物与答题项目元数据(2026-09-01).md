## 四、选型结论

1. 宠物层：功能最完整且有明确许可证的是 **ClassPet（AGPL-3.0）**；开箱规则最多、SQLite 零配置、有在线演示的是**班级宠物园**（但无许可证）。**两者都没有社区，需自担维护。**
2. 答题层：**ClassQuiz** 是唯一兼具成熟度（⭐711、2022 年至今活跃）、明确许可证（MPL-2.0）与自建文档的选项。
3. 若不想承担维护成本，建议先用"表格 + 宠物图片"的零代码 MVP 验证机制有效性（见主文档路线 A）。
