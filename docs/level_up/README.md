# level_up：新手数学辅导老师进阶手册

> 你的处境：小区里的实习社数学晚间辅导老师，学生两极——一边是"连加法交换律都不熟"的初一新生，一边是年级前三的中考冲刺生。
> 你的问题：怎么做，才能更受学生欢迎、教学水平更高？
> 本目录：7 个主题文件夹，每个主题一篇带出处的调研文档。**所有论点均标注信源（官方讲座实录/公开论文/权威机构报告/头部创作者公开数据），无源头内容一律不收录。**

## 一句话总纲

> **受学生欢迎的顺序是：先被信任（降焦虑、给成功体验），再被需要（分层提分），最后被喜欢（用他们的语言和媒介教数学）。**

这个顺序不是鸡汤，有数据链支撑：PISA 2022 显示数学焦虑每升 1 分成绩平均降 18 分、师生关系与成绩正相关（详见 02 号文档）；游戏化元分析显示即时反馈与个人进步机制显著提升动机（详见 04 号文档）。

## 两类学生的速查策略卡

**基础薄弱的初一新生**
1. 第一节课不出卷，先聊焦虑（PISA：焦虑-成绩负相关）；
2. 补结构不补题量：运算律结构图把小学漏洞和初一内容焊接（马云鹏"一致性"）；
3. 目标"守 70%"：深圳中考七成基础题源自教材，吃透教材即可及格；
4. 教材精读代替刷卷（风云老师：新教材适合自学，立足教材是正道）。

**年级前三的中考冲刺生**
1. 不教解题教审题：新定义题专项（逐字拆定义→复述规则→自己举例→做题）；
2. 过程规范审计：按阅卷标准逐行批"这里扣 1 分"；
3. 基础板块限时 40 分钟，时间省给压轴；
4. 做焦虑的"定海神针"：顶尖学生（尤其女生）焦虑更高，用成长型思维话术归因错题。
