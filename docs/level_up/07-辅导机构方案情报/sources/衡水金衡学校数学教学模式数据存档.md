# 衡水系（衡水金衡学校）教学模式数据存档

> - 来源：培优邦教育网（金衡学校课程优势/四环教学法）、校学网（初二暑期班/全托）、廊坊新闻网（衡水初中1对1推荐）
> - 抓取时间：2026-09-01（WebSearch 检索）
> - 用途：07号文档衡水系条目依据

## 四环教学法（每节课闭环）
精讲知识 → 专题训练 → 套卷演练 → 仿真模拟
目标：当堂消化、当天巩固、当周检测

## 管理与讲练
- "2+1+1"管理：2天新课 + 1天复习 + 1天检测，循环推进
- "2+1"讲练：每2节讲授配1节练习，讲完即练、练完即评，治"听得懂做不出"
- 车轮式复习 + 黄金周训练（考前集中突破高频考点）

## 分层与面批
- 分层 A/B/C 班：A攻压轴、B强化中档、C突破基础；数学压轴题得分率可提升20%
- 高频面批：每科每班老师每天单独辅导≥6名学生，2天一轮全覆盖（30人班每生每2天至少1次面批）
- 校本工具：三色笔记法（黑=定义、红=考点、蓝=易错）、高频考点云图、错题本模板

## 数学重点
函数与几何两大难点；"一题多解"；配《初二数学压轴题集》《几何模型库》（辅助线技巧）

## 基础薄弱专项
"低起点、慢节奏、重基础、多复盘"：先梳理课本核心知识点，每节课设基础过关环节，配套基础巩固习题+定期复盘

## 全封闭与心理
每日6:30–22:30；每周1节情绪疏导课；家校周报（课堂表现/作业/成绩，专属APP）

## 收费参考（初二全托40天）
学费12,800 + 住宿3,000 + 餐饮2,400 ≈ 18,200元/期；签约提分30–50分（未达标免费重读）
